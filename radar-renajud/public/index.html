🚀 Publicar na Vercel
Deploy gratuito, HTTPS automático, CDN global. Siga os passos:
1

Baixe o arquivo HTML

Clique em Download no topo desta conversa para salvar o arquivo radar-renajud.html.

2

Crie uma conta na Vercel

Acesse (gratuito, sem cartão):

🔗 vercel.com/signup
3

Crie um repositório no GitHub

Suba o arquivo para um repositório novo, dentro de uma pasta public/, com o nome index.html.

🔗 github.com/new
4

Importe na Vercel

No dashboard: Add New → Project, conecte o GitHub e selecione o repositório.

# Configurações de build
Framework: Other
Build Command: (vazio)
Output Directory: public
5

✅ Pronto! Site no ar

A Vercel gera um link como radar-renajud.vercel.app em 30 segundos. Qualquer push no GitHub atualiza o site automaticamente.

6

Domínio próprio (opcional)

Em Settings → Domains adicione seu domínio (ex: radarrenajud.com.br). O plano Hobby da Vercel é gratuito até 100GB/mês.
